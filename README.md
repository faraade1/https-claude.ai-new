# Printwise reseller operations

A lightweight, no-install starter workspace for a copier and print-equipment reseller. It brings equipment records, service calls, supply inventory, customer accounts, and quotes together in one browser-based dashboard.

## Run it

Open `index.html` in a modern browser. No build step, package installation, or server is required. New records are persisted to the browser's local storage on that device.

## What's included

- Overview dashboard with service, stock, and quote counts
- Equipment, service desk, supplies, customer, and quote lists
- Search across records and simple add-record forms
- Example data to demonstrate the workflow

## Before using for real business

This is a front-end prototype, not a multi-user system. Data remains in the current browser and is not backed up or shared with staff. Replace sample data, add authentication and a secure shared database, and validate pricing, inventory, service agreements, device compatibility, and any integrations before relying on it operationally.
